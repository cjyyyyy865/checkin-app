# 打卡小助手 📅🪙

一个手机打卡 App（PWA），无需安装任何依赖，数据全部保存在手机本地，完全离线可用。

## 功能

- ✅ **任务打卡**：点击卡片即可打卡，再点取消；今天全部完成有撒花庆祝
- 🔁 **重复规则**：每天刷新、固定"每周一、周二"，或 **仅一次的临时任务**（只在这一天出现，适合一次性事项）
- ⚡ **快速添加**：新建任务时勾选"存为常用模板"，以后在今日页点"＋ 添加任务"即可从模板**一键添加**，不用再填表单；内置喝水、阅读、运动等常用模板
- ⏳ **倒数日**：考研、生日、旅行……关键日期倒计时，今天页横滑卡片展示，自动按最近排序
- ⏱ **时长记录**：任务可开启"记录时长"（如锻炼了多少分钟），打卡时快捷选择或输入
- 📈 **时长统计**：折线趋势 + 柱状图，日 / 周 / 月 / 年 + 总时长，可按项目筛选
- 🪙 **金币奖励**：每次打卡按任务设定获得金币，取消打卡会扣回
- 🔥 **连续天数**：每个任务和总体都有连续打卡统计（今天还没打卡不打断连续）
- 🎁 **奖品兑换**：自定义奖品（名称/图标/所需金币），攒够金币一键兑换，保留兑换记录
- 📊 **完成统计**：日 / 周 / 月 / 年四种视图 + 按任务筛选；月历热力图、柱状图、打卡次数 / 完成率 / 最长连续
- ✏️ **补打卡**：在统计的日历或某天明细里点击历史日期即可补签（同样发放/扣回金币）
- 🖼️ **壁纸轮换**：内置多张壁纸卡片，每次切换页面随机换一张（含动图）；模糊底衬 + 小图卡片不遮挡人物，可在设置中关闭动效或背景
- 🌙 **深色模式**：跟随系统或手动切换
- 💾 **数据导出 / 导入 / 清空**：JSON 备份，换手机不丢数据

## 手机上使用（安装到主屏幕）

第一步 —— 起一个本地服务（在 `checkin-app` 目录下，任选其一）：

```bash
# 电脑上运行，手机和电脑连同一个 Wi-Fi
npx serve .
# 或
python -m http.server 8080
```

第二步 —— 用手机浏览器访问电脑 IP（如 `http://192.168.x.x:8080`），然后：

- **iPhone（Safari）**：分享 → 添加到主屏幕
- **Android（Chrome）**：菜单 → 添加到主屏幕 / 安装应用

之后从主屏幕图标打开即是全屏 App，可离线使用。

> 电脑上直接双击 `index.html` 也能用（功能正常，只是没有离线缓存）。

## 数据说明

- 数据保存在浏览器 `localStorage`（键名 `checkin_app_v1`），不联网、不上传
- 统计里"获得金币"按打卡当时的任务金币值精确记录
- 停用任务不会丢失历史记录，仍可在统计中查看；删除任务会同时删除其打卡记录
